ENTRADAS: 
- Usuario o cédula: Valores por parámetro de tipo String (JTextField)
- Contraseña: Valores por parámetro de tipo String (JPasswordField)

PRECONDICIONES (Casos de prueba / Clases de equivalencia):

1. Usuario vacío y contraseña vacía.
2. Usuario vacío, pero contraseña con valor.
3. Usuario con valor, pero contraseña vacía.
4. Usuario incorrecto, con contraseña correcta.
5. Usuario correcto, pero contraseña incorrecta.
6. Usuario registrado y contraseña correcta (Caso de éxito).

ESPECIFICACIONES:
validarInicioSesion(): Devuelve un mensaje de éxito (String) en caso de que el usuario/cédula exista en la base de datos y la contraseña coincida. Devuelve un mensaje descriptivo de error (String) si hay campos en blanco o credenciales erróneas.

SALIDAS:

1- Complete todos los campos
2- El usuario no puede estar vacío
3- La contraseña no puede estar vacía
4- Usuario no encontrado
5- Contraseña incorrecta
6- Inicio de sesión exitoso

- CLASES DE EQUIVALENCIA: ("", contraseña con valor)

- CLASES DE EQUIVALENCIA: (usuario con valor, "")
